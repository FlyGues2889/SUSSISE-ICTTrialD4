## 3. 后端启动

### 3.1 创建 conda 环境（Python 3.12）

```bash
conda create -n d4 python=3.12 -y
conda activate d4
```

### 3.2 安装依赖

```bash
cd project/backend
pip install -r requirements.txt
```

### 3.2 配置环境变量

通过环境变量或 `.env` 文件配置数据库连接：

| 变量 | 默认值 | 说明 |
|------|--------|------|
| `DB_HOST` | 127.0.0.1 | MySQL 主机 |
| `DB_PORT` | 3306 | MySQL 端口 |
| `DB_USER` | root | MySQL 用户名 |
| `DB_PASS` | （空） | MySQL 密码 |
| `DB_NAME` | sedentary_health | 数据库名 |
| `JWT_SECRET` | sedentary-health-secret-2026 | JWT 签名密钥 |

### 3.3 初始化数据库

```bash
# 1. 创建数据库
mysql -u root -p -e "CREATE DATABASE IF NOT EXISTS sedentary_health CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;"

# 2. 导入建表 SQL
mysql -u root -p sedentary_health < db/schema.sql

# 3. 导入方案种子数据（36 个运动方案）
mysql -u root -p sedentary_health < db/seed_plans.sql
```

### 3.4 启动服务

```bash
cd project/backend
uvicorn app.main:app --host 0.0.0.0 --port 8001 --reload
```

启动后访问 http://127.0.0.1:8001/docs 查看 Swagger API 文档。

## 4. 前端启动

### 4.1 安装依赖

```bash
cd project/frontend
pnpm install
```

### 4.2 开发模式

```bash
pnpm dev
```

启动后访问 http://localhost:5174，API 请求自动代理到后端 `127.0.0.1:8001`。

### 4.3 生产构建

```bash
pnpm build
```

产物输出到 `frontend/dist/`，用 Nginx 托管静态文件即可。

## 6. Skills 模块

4 个自定义 Skill 位于 `D4/skills/` 目录，后端通过 `sys.path` 自动加载：

| Skill | 文件 | 功能 |
|-------|------|------|
| posture_assessment | `skills/posture_assessment.py` | 体态评估评分（肩颈/腰背各 8 题 + 安全红线） |
| plan_matcher | `skills/plan_matcher.py` | 方案匹配推荐（加权排序取前 3） |
| safety_check | `skills/safety_check.py` | 安全边界检查（红线/高风险/既往史 → 就医提示） |
| qa_responder | `skills/qa_responder.py` | 智能问答（关键词匹配知识库） |

方案库生成脚本：

```bash
cd D4
python skills/generate_plans.py
# 输出：project/backend/db/seed_plans.sql（36 个方案）
```

## 8. 华为云部署

### 8.1 资源清单

| 资源 | 规格 | 用途 |
|------|------|------|
| ECS | 2vCPU/2GB/40GB | 前后端部署 + Nginx |
| RDS MySQL | 通用型 2vCPU/2GB/40GB | 数据持久化 |
| DCS Redis | 单机 128MB | 缓存与会话 |

### 8.2 部署步骤

```bash
# 1. ECS 安装 Docker
yum install -y docker && systemctl start docker

# 2. RDS 创建实例后导入数据
mysql -h <RDS_HOST> -u <USER> -p <DB_NAME> < db/schema.sql
mysql -h <RDS_HOST> -u <USER> -p <DB_NAME> < db/seed_plans.sql

# 3. 后端部署
cd project/backend
pip install -r requirements.txt
nohup uvicorn app.main:app --host 0.0.0.0 --port 8001 &

# 4. 前端构建 + Nginx 托管
cd project/frontend
pnpm install && pnpm build
# 将 dist/ 部署到 Nginx 静态目录

# 5. Nginx 反向代理配置
# location / { root /path/to/dist; }
# location /api { proxy_pass http://127.0.0.1:8001; }
```

### 8.3 环境变量（华为云）

```bash
export DB_HOST=<RDS内网IP>
export DB_PORT=3306
export DB_USER=<RDS用户>
export DB_PASS=<RDS密码>
export DB_NAME=sedentary_health
export JWT_SECRET=<随机密钥>
```

## 10. 常见问题

**Q: 后端启动报 `ModuleNotFoundError: No module named 'aiomysql'`**  
A: 未安装依赖，执行 `pip install -r requirements.txt`。

**Q: 前端页面空白**  
A: 后端未启动或端口不对，确认 `uvicorn` 运行在 8001 端口，`vite.config.js` 代理配置正确。

**Q: 方案推荐返回空列表**  
A: 未导入种子数据，执行 `mysql < db/seed_plans.sql` 导入 36 个方案。

**Q: 评估提交后没有就医提示**  
A: 就医提示仅在安全红线条目（N5/B5）得分≥1 或区域总分≥13 时触发，检查问卷答案是否命中阈值。
