## 3. 后端启动

### 3.1 创建 conda 环境（Python 3.12）

```bash
conda create -n d4 python=3.12 -y
conda activate d4
```

### 3.2 安装依赖

```bash
cd project/backend
pip install -r requirements.txt
```

### 3.2 配置环境变量

通过环境变量或 `.env` 文件配置数据库连接：

| 变量 | 默认值 | 说明 |
|------|--------|------|
| `DB_HOST` | 127.0.0.1 | MySQL 主机 |
| `DB_PORT` | 3306 | MySQL 端口 |
| `DB_USER` | root | MySQL 用户名 |
| `DB_PASS` | （空） | MySQL 密码 |
| `DB_NAME` | sedentary_health | 数据库名 |
| `JWT_SECRET` | sedentary-health-secret-2026 | JWT 签名密钥 |
| `AI_PROVIDER` | none | 问答兜底 AI，取 `huawei` 才启用 |
| `HUAWEI_AI_ENDPOINT` | （空） | 对话补全地址（OpenAI Chat Completions 协议） |
| `HUAWEI_AI_TOKEN` | （空） | 调用令牌 |
| `HUAWEI_AI_MODEL` | pangu | 模型名 |
| `AI_TIMEOUT` | 15 | AI 请求超时（秒） |

### 3.3 初始化数据库

```bash
# 1. 创建数据库
mysql -u root -p -e "CREATE DATABASE IF NOT EXISTS sedentary_health CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;"

# 2. 导入建表 SQL
mysql -u root -p sedentary_health < db/schema.sql

# 3. 导入方案种子数据（36 个运动方案）与知识库
mysql -u root -p sedentary_health < db/seed_plans.sql
mysql -u root -p sedentary_health < db/seed_kb.sql
```

### 3.4 启动服务

```bash
cd project/backend
uvicorn app.main:app --host 0.0.0.0 --port 8001 --reload
```

启动后访问 http://127.0.0.1:8001/docs 查看 Swagger API 文档。

## 6. Skills 模块

4 个自定义 Skill 位于 `D4/skills/` 目录，后端通过 `sys.path` 自动加载：

| Skill | 文件 | 功能 |
|-------|------|------|
| posture_assessment | `skills/posture_assessment.py` | 体态评估评分（肩颈/腰背各 12 题，6 维度加权，四档风险） |
| plan_matcher | `skills/plan_matcher.py` | 方案匹配推荐（加权排序取前 3） |
| safety_check | `skills/safety_check.py` | 安全边界检查（红线/高风险/既往史 → 就医提示） |
| qa_responder | `skills/qa_responder.py` | 智能问答（关键词匹配知识库；未命中时由 `app/services/ai.py` 调 AI 兜底，未配置则返回固定拒答文案） |

方案库生成脚本：

```bash
cd D4
python skills/generate_plans.py
# 输出：project/backend/db/seed_plans.sql（36 个方案）
```

## 7. API 接口一览

| 方法 | 路径 | 说明 | 认证 |
|------|------|------|------|
| POST | /api/auth/register | 用户注册 | 否 |
| POST | /api/auth/login | 用户登录 | 否 |
| POST | /api/auth/demo-login | 演示账号登录（`{"profile":"normal"\|"high"}`） | 否 |
| POST | /api/assessment | 提交体态评估 | 是 |
| GET | /api/assessment/history | 评估历史 | 是 |
| GET | /api/plans/recommend | 推荐方案（`risk_level=high` 时返回空列表 + `blocked:true`） | 是 |
| GET | /api/plans/{id} | 方案详情 | 否 |
| GET | /api/plans | 方案列表 | 否 |
| GET | /api/plans/movement-pool | 自定义方案动作池 | 否 |
| GET | /api/plans/favorites | 我的收藏 | 是 |
| POST | /api/plans/{id}/favorite | 收藏/取消收藏 | 是 |
| POST | /api/plans/custom | 新建自定义方案 | 是 |
| DELETE | /api/plans/custom/{id} | 删除自定义方案 | 是 |
| POST | /api/training | 记录训练 | 是 |
| GET | /api/training/stats | 训练统计 | 是 |
| GET | /api/training/streak | 连续打卡天数 | 是 |
| PUT | /api/reminder | 设置提醒 | 是 |
| GET | /api/reminder | 查询提醒 | 是 |
| POST | /api/qa | 智能问答（请求体 `{"question","history":[...]}`，返回 `source: local\|ai`） | 是 |
| GET | /api/health | 健康检查 | 否 |

认证方式：请求头 `Authorization: Bearer <token>`，注册/登录时返回。

问答采用三级降级：本地知识库置信度 ≥ 0.25 直接返回（`source: local`）；低于阈值且配置了 `AI_PROVIDER=huawei` 时调用华为云 AI（`source: ai`）；AI 未配置或调用失败返回固定拒答文案并建议就医。多轮对话通过 `history` 传入最近 4 条消息。

## 8. 华为云部署

完整步骤、systemd 单元、Nginx 配置与上线验收清单见 `project/deploy/README.md`，这里只列要点。

### 8.1 资源清单

| 资源 | 规格 | 用途 |
|------|------|------|
| ECS | 2vCPU/2GB/40GB | Nginx + 后端 |
| RDS MySQL | 8.0，同 VPC | 数据持久化 |
| DCS Redis | 单机 128MB（可选） | 方案/问答/连续打卡缓存 |

### 8.2 关键命令

```bash
# 后端：建表、36 个方案、10 条知识库都在启动时自动补种
cd project/backend
python3.11 -m venv .venv && .venv/bin/pip install -r requirements.txt
sudo cp ../deploy/sedentary-api.service /etc/systemd/system/
sudo systemctl enable --now sedentary-api

# 前端：云模式构建（关闭本地 Mock）
cd project/frontend && pnpm build:cloud
sudo cp -r dist/* /var/www/d4/

sudo cp ../../deploy/nginx.conf /etc/nginx/conf.d/d4.conf
sudo nginx -t && sudo systemctl reload nginx

# 演示数据（推荐）
python project/backend/scripts/seed_demo.py
```

### 8.3 环境变量（华为云）

```bash
export DB_HOST=<RDS内网IP>
export DB_PORT=3306
export DB_USER=<RDS用户>
export DB_PASS=<RDS密码>
export DB_NAME=sedentary_health
export JWT_SECRET=<随机密钥>
export REDIS_URL=<可选，留空则用进程内缓存>
export AI_PROVIDER=<可选，huawei 时启用问答 AI 兜底>
export HUAWEI_AI_ENDPOINT=<对话补全地址>
export HUAWEI_AI_TOKEN=<调用令牌>
export HUAWEI_AI_MODEL=pangu
export AI_PROVIDER=<可选，取 huawei 时启用问答 AI 兜底>
export HUAWEI_AI_ENDPOINT=<对话补全地址>
export HUAWEI_AI_TOKEN=<调用令牌>
export HUAWEI_AI_MODEL=pangu
```

注意：`.env` 是本地 Mock 模式，`.env.cloud` 才是云模式；用 `pnpm build` 构建出的产物会走 Mock，不能上云。

## 10. 常见问题

**Q: 后端启动报 `ModuleNotFoundError: No module named 'aiomysql'`**  
A: 未安装依赖，执行 `pip install -r requirements.txt`。

**Q: 前端页面空白**  
A: 后端未启动或端口不对，确认 `uvicorn` 运行在 8001 端口，`vite.config.js` 代理配置正确。

**Q: 方案推荐返回空列表**  
A: 未导入种子数据，执行 `mysql < db/seed_plans.sql` 导入 36 个方案。

**Q: 评估提交后没有就医提示**  
A: 就医提示在红线题（N5/N11/B5/B11）得分 ≥2、单侧加权总分 ≥23.79，或既往史命中「颈椎病/腰椎间盘突出/骨折/术后/急性」时触发。

**Q: 问答总是返回「暂时无法回答」**  
A: `knowledge_base` 为空时启动会自动补种 10 条；若仍是空表，确认 `project/backend/db/seed_kb.sql` 随代码一起部署。

**Q: 云上部署后页面能开但接口 401**  
A: `JWT_SECRET` 未设置或前后端实例不一致；多实例部署必须共用同一个密钥。
