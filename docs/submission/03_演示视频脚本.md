# 演示视频脚本

**项目名称**：久坐肩颈腰背科学运动干预助手
**成片时长**：4 分 10 秒（要求 3–5 分钟）
**录制方式**：浏览器 390×844 移动视口录制，全程无剪辑跳帧
**演示账号**：`990001`（常规演示，5 轮评估历史）/ `990002`（高风险演示，红线命中）

---

## 一、拍摄前准备清单

| 检查项 | 要求 |
|---|---|
| 后端 | `8001` 已启动，`python -m compileall` 与启动日志无报错 |
| 前端 | 已执行 `pnpm build:cloud` 并部署，或本地 `pnpm dev` |
| 数据 | 已执行 `python project/backend/scripts/seed_demo.py --reset` |
| 演示账号 | 登录页点「演示账号」，`990001` 有 5 轮评估、7 条训练记录、连续打卡 5 天 |
| 高风险账号 | 登录页点「高风险演示」，`990002` 已触发红线，用于安全拦截镜头 |
| 演示数据来源 | 后端执行 `seed_demo.py`（云端）或页面自动载入 `mock/demo.js`（本地 Mock） |
| 浏览器 | 关闭书签栏、通知、其他标签页；缩放 100% |
| 输入法 | 中文输入法切到英文，避免录制时弹出候选框 |
| 网络 | 关闭代理，确认首屏加载 < 2 秒 |

## 二、分镜表

### 镜头 1｜开场：问题陈述（0:00–0:20）

- **画面**：首页首屏，不动，鼠标不出现。
- **操作**：无。
- **旁白**：*"每天坐八小时的人，几乎都知道该起来动一动。但很少有人能回答三个问题：我现在有多严重、我该做哪几个动作、什么情况下我不该动。这三个问题，就是我们要解决的问题。"*
- **字幕**：久坐人群 3 亿+｜知道该动，但不知道动什么

### 镜头 2｜进入产品（0:20–0:35）

- **操作**：点击"演示账号"按钮，直接进入首页。
- **画面**：首页「今天建议」卡片 + 连续打卡 5 天。
- **旁白**：*"产品不要求注册表单。进入后只有一件事要做：先评估。首页只保留今天建议和打卡进度。"*
- **强调**：指出首页只有一个主按钮，没有信息堆砌。

### 镜头 3｜评估：一题一屏（0:35–1:15）

- **操作**：进入 `/assessment`，依次回答 5–6 题（不必录完 24 题，第 6 题后切镜）。
- **画面**：进度条、单题四档选项、选中后按钮才可用。
- **旁白**：*"肩颈 12 题、腰背 12 题，按疼痛频率、僵硬、活动受限、姿势习惯、神经症状、功能影响六个维度加权。一题一屏，是为了让用户不必在一屏里面对 24 个选项。"*
- **必须拍到的细节**：跨部位跳转时的过渡、未选中时"下一题"不可点。

### 镜头 4｜报告：分数 + 依据（1:15–1:45）

- **操作**：提交后停在报告页，缓慢下滚一次再回滚。
- **画面**：风险等级标签、总分、六维度条形、主要问题点、健康依据引用。
- **旁白**：*"报告给出的不是一句'你的颈椎不好'。总分、等级、问题点、每一条建议的机构出处都在这里，单侧满分 36.6 分，四档风险分级。"*
- **必须拍到**：健康依据里出现的机构名称（WHO / CSEP / NHS）。

### 镜头 5｜安全拦截（1:45–2:05）★ 差异化镜头

- **操作**：退出，在登录页点「高风险演示」，重做评估中勾选红线题（如手麻、夜间痛醒）；或直接展示该账号已有的高风险报告。
- **画面**：报告页顶部出现就医提示，方案入口被拦截。
- **旁白**：*"这是产品和其他健身类应用最不一样的地方。出现放射性疼痛、肢体麻木、夜间痛醒这类警示信号，我们不推荐训练，直接建议就医。宁可少一个用户，不冒一次风险。"*
- **必须拍到**：提示文案完整可读，停留 3 秒以上。

### 镜头 6｜方案：三维匹配 + 收藏 + 自定义（2:05–2:45）

- **操作**：切回 `990001`，进入 `/plans`；展示 3 个推荐方案及匹配度；点一次心形收藏；切到"我的收藏"；再打开自定义方案表单，选部位、时长、场景、勾 3 个动作，保存。
- **旁白**：*"方案按部位、时长、场景三维匹配，官方 36 个方案覆盖 3 分钟到 15 分钟。不合心意的，可以收藏，也可以自己组合动作池里的动作建一个方案。"*
- **必须拍到**：收藏后心形变实心、"我的收藏"数量增加、自定义方案带标记出现在列表。

### 镜头 7｜跟练 + 打卡（2:45–3:10）

- **操作**：点进任一方案，进入 `/session/:planId`，等一个动作倒计时走完 5 秒，点"完成"，自动打卡。
- **画面**：动作名称、剩余秒数、动作要领、上一/下一动作。
- **旁白**：*"跟练页逐个动作倒计时，给的是要点不是视频。做完自动打卡，不需要用户再点一次'我完成了'。"*

### 镜头 8｜追踪与趋势（3:10–3:40）

- **操作**：进入 `/tracking`，依次指出：提醒设置（45 分钟）、本周统计、活跃天数、改善趋势折线（肩颈从 21 分降到 13 分）、部位关注度条形。
- **旁白**：*"五轮评估之后，趋势线是往下走的。这条线是产品能不能留住用户的关键——它让'我在变好'变成看得见的东西。"*
- **必须拍到**：折线上两条不同颜色的线、阈值虚线、部位关注度百分比。

### 镜头 9｜指南与问答（3:40–4:00）

- **操作**：进入 `/guidelines` 展示 9 条机构指南；再进入 `/qa` 提问"久坐多久需要起身活动"。
- **画面**：问答返回带出处的答案，答案卡片标注"知识库"；再提一个知识库未覆盖的问题，若云端已配 `AI_PROVIDER` 则显示"AI 回答"，否则显示"暂时无法回答"。
- **旁白**：*"所有建议都能追溯到机构指南原文。问答优先在知识库范围内回答，答不了的明确说答不了；云端可选接入大模型兜底，但不允许它做诊断。"*

### 镜头 10｜收尾（4:00–4:10）

- **画面**：回到首页，定格。
- **旁白**：*"评估、方案、跟练、打卡、趋势，一个闭环。这是久坐人群真正用得下去的运动干预。"*
- **字幕**：SUS SISE｜华为 ICT 大赛创新赛道

## 四、常见录制事故与预案

| 事故 | 预案 |
|---|---|
| 演示账号数据被上一次录制改脏 | 重跑 `seed_demo.py --reset`，10 秒内恢复 |
| 趋势折线只有 1 个点不显示 | 确认 `990001` 有 5 轮历史；不足 2 次评估时页面显示空态而非报错 |
| 高风险账号没触发拦截 | 确认勾选至少 2 道红线题，或总分 ≥ 23.79 |
| 问答命中率低 | 用脚本内置的示例问题，不要临场自由发挥 |
| 问答回答了但没标来源 | 确认演示环境是否配置 `AI_PROVIDER`；未配置时答案卡片应显示「知识库」，配置后低置信度问题显示「AI 回答」 |
| 首屏白屏 | 检查是否误用了 `pnpm build`（Mock 模式产物需配合 Mock 数据），上云必须 `pnpm build:cloud` |
