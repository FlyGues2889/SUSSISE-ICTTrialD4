## 二、部署完成后必须自测的 9 项

| # | 检查项 | 通过标准 |
|---|---|---|
| 1 | 首屏可访问 | 手机 4G 网络下 3 秒内出现首页，无白屏 |
| 2 | 注册可用 | 新用户名注册成功并自动登录 |
| 3 | 评估闭环 | 24 题答完得到报告，含等级、总分、问题点、依据 |
| 4 | 高风险拦截 | `990002` 登录后报告出现就医提示，方案入口被拦截 |
| 5 | 方案与打卡 | 选方案 → 跟练 → 打卡成功，首页连续天数 +1 |
| 6 | 收藏与自定义 | 收藏后出现在"我的收藏"，自定义方案可创建与删除 |
| 7 | 趋势图 | `/tracking` 显示改善趋势折线，至少 2 个数据点 |
| 8 | 问答与降级 | 知识库内问题有答案并标注「知识库」；范围外问题在未配置 `AI_PROVIDER` 时返回"暂时无法回答"，配置后返回「AI 回答」且不做诊断 |
| 9 | 提醒跨页生效 | 在 `/tracking` 设置 1 分钟间隔，切到首页或后台标签页仍按时弹出页内提醒 |

任一项不通过则视为演示失败，不得对外提供地址。

## 三、部署路径速查

```bash
# 服务器上执行
cd /opt/d4
git pull

# 前端（注意必须是 build:cloud，build 走 Mock 数据）
cd project/frontend && pnpm install --frozen-lockfile && pnpm build:cloud
sudo rsync -a --delete dist/ /var/www/d4/

# 后端
cd /opt/d4/project/backend && source .venv/bin/activate
pip install -r requirements.txt
python -m compileall -q app
sudo systemctl restart sedentary-api
sudo systemctl status sedentary-api --no-pager

# 演示数据（首次或需复位时）
python scripts/seed_demo.py --reset
```

详细资源清单、Nginx 配置、systemd 单元、环境变量模板见 `project/deploy/`。

## 四、线上不可用时的兜底方案

| 场景 | 兜底做法 |
|---|---|
| 现场网络不可用 | 使用提前录制的 `03_演示视频脚本.md` 对应成片 |
| 云主机故障 | 本地 `pnpm dev` + `uvicorn` 起完整环境，数据来自 `seed_demo.py` |
| RDS 连接失败 | 切换 SQLite（`DB_URL=sqlite+aiosqlite:///./d4.db`），跑 `schema_sqlite.sql` 再 `seed_demo.py` |
| 只展示前端 | 用 `pnpm build`（Mock 模式）产物 + `mock/db.js` 内置演示数据，后端不启动也能走完整闭环 |
