## 一、项目背景与问题定义

久坐已经成为办公、学习场景的常态。世界卫生组织在《关于身体活动和久坐行为的指南（2020）》中明确指出，长时间静坐与全因死亡风险升高相关，并建议成年人用任何强度的活动替代久坐时间。现实中的矛盾在于：**知道该动，但不知道动什么、动多久、怎么判断能不能动。**

我们把这个问题拆成四个具体缺口：

1. **评估缺口**：网上大量"颈椎自测"只有总分，不区分疼痛频率、僵硬、活动受限、姿势习惯、神经症状、功能影响，也无法给出可执行的下一步。
2. **方案缺口**：通用拉伸视频与办公场景脱节。用户需要的往往是"3 分钟、在工位、不用换衣服"的动作组合，而不是 40 分钟完整课程。
3. **安全缺口**：肩颈腰背不适中有一部分属于需要就医的警示信号（放射性疼痛、肢体麻木无力、夜间痛醒）。普通健身产品不设拦截，存在把神经根刺激当作肌肉紧张来训练的风险。
4. **依从性缺口**：评估、方案、提醒、记录分散在不同工具里，用户做完一次评估就流失。

本项目用一个闭环产品回应这四点：**评估 → 报告 → 方案 → 跟练 → 打卡 → 趋势**，并把每一条健康建议都标注到可查证的机构指南原文。

## 二、产品设计

### 2.1 核心闭环

用户首次进入只看到一件事：做一次评估。24 道题（肩颈 12 题、腰背 12 题）一题一屏，答完立即得到报告：风险等级、总分、主要问题点、建议、健康依据。报告页只有一个主动作——"去选择运动方案"。

方案页按"部位 × 时长 × 场景"三个维度推荐，默认给出 3 个匹配方案并显示匹配度。选一个进入跟练，逐个动作倒计时，结束后自动打卡。回到首页可以看到"今天建议"与连续打卡天数；"提醒与追踪"页把提醒设置、周统计、月统计、改善趋势、部位关注度放在一起。

### 2.2 评估模型

肩颈与腰背各 12 题，选项统一四档（无 / 偶尔 / 经常 / 持续，0–3 分），按六个维度加权：

| 维度 | 权重 | 设计意图 |
|------|------|----------|
| 疼痛频率 | 1.0 | 反映症状的持续性 |
| 僵硬程度 | 0.8–1.0 | 反映组织顺应性下降 |
| 活动受限 | 1.0 | 反映功能影响 |
| 姿势习惯 | 0.8 | 反映可干预的行为因素 |
| 神经症状 | 1.5 | 警示信号，权重最高 |
| 功能影响 | 0.8–1.0 | 反映对生活与睡眠的干扰 |

单侧满分 36.6 分（3 × 权重和 12.2）。风险分四档：<12.81 低风险，12.81–18.3 中低风险，18.3–23.79 中高风险，≥23.79 高风险；红线题（N5/N11/B5/B11）得分 ≥2 时直接判定高风险。四档设计是为了让"有症状但可运动"与"症状明显需就医"之间有一层缓冲，避免二分类带来的过度保守或过度激进。

结果不只给分数，还给**问题点**：某维度得分达到该维度满分的 40% 才列入，按得分降序输出，最多展示四个标签。用户看到的是"疼痛频率偏高、姿势习惯不良"，而不是"你得了颈椎病"。

### 2.3 安全边界

系统在三个位置设置硬边界：

1. **红线题**：颈部疼痛放射至手臂或手指、手部握力下降、下肢麻木放射痛、夜间痛醒，任一项达到"经常"即触发就医提示并停止推荐方案。
2. **高风险**：总分 ≥23.79 时，首页显示"高风险期间先遵医嘱"，方案推荐返回空列表，跟练入口不出现。
3. **既往史**：注册时可填写既往史，命中"颈椎病、腰椎间盘突出、骨折、术后、急性"时提示在医生指导下运动。

产品文案明确声明：本工具提供健康运动指导，不替代医疗诊断。这是产品的伦理底线，不是免责套话——它决定了高风险用户在产品内**拿不到**运动方案。

### 2.4 指南可溯源

产品内 9 条健康依据来自 5 家机构：世界卫生组织（WHO）、加拿大运动生理学学会（CSEP）、英国国家医疗服务体系（NHS）、英国特许物理治疗学会（CSP）、美国卫生与公众服务部（HHS）。每条依据包含中文节选、英文原句、机构、年份与原文链接，分布在四个位置：

- 首页「今天建议」下方 2 条；
- 评估报告「健康依据」1 条 + 全部指南入口；
- 跟练页 1 条（颈部优先 CSP，腰背优先 NHS）；
- 「我的 → 指南依据」可按部位筛选全部 9 条。

我们刻意避免"专家建议"这类无法核验的表述。评审可以点开任意一条链接看到原文。

### 2.5 方案库

36 个方案 = 3 个部位（肩颈 / 腰背 / 全身）× 4 个时长（3 / 5 / 10 / 15 分钟）× 3 个场景（办公桌前 / 站立休息 / 居家），共 243 条动作条目、36 个去重动作。每个方案包含动作序列、单动作时长与要领、适用风险等级、禁忌说明。

匹配算法按部位、时长、场景加权打分，高风险时过滤含禁忌的方案，取前 3 名并展示匹配度。用户也可以收藏常用方案，或从部位动作池里自建方案——自定义方案同样走同一套跟练与打卡链路。

### 2.6 智能问答

问答库覆盖久坐时长、肩颈酸痛、腰痛、训练频率、高风险处理、疼痛加重、工位动作、延迟性酸痛、提醒设置、就医指征 10 个主题。匹配采用关键词长度加权：`命中关键词总长度 / 全部关键词总长度`，仅在无关键词命中时回退到整句包含判断，阈值 0.1。这样"久坐多久要起来"能命中"久坐多久需要起身活动"，而未配置 AI 兜底时"今天天气怎么样"会明确返回无法回答，不会编造。

前后端共用同一套匹配规则（前端 Mock 与 `skills/qa_responder.py`），保证演示与云端行为一致。知识库置信度低于 0.25 时，云端可选调用华为云 AI 兜底（`AI_PROVIDER=huawei`），系统提示词硬性禁止诊断、限定只答久坐与肩颈腰背相关问题，未配置或调用失败则返回固定拒答文案与就医建议。

## 三、技术实现

### 3.1 架构

前端 Vue 3 + Vite，纯自研组件库（不使用 UI 框架），平面极简设计：白卡 + 1px 边框 + 大圆角 + 留白，无阴影、无毛玻璃。后端 FastAPI + SQLAlchemy 异步，MySQL 8.0（本地可切 SQLite 零依赖启动）。四个自定义 Skill 以纯 Python 模块形式被后端加载，前端 Mock 复用同一套算法逻辑。

```
浏览器 → Nginx（静态 + /api 反代）→ FastAPI
                                    ├─ Skills：posture_assessment / plan_matcher / safety_check / qa_responder
                                    ├─ RDS MySQL：user / assessment / exercise_plan / training_log / reminder_setting / knowledge_base / plan_favorite / custom_plan
                                    └─ DCS Redis（可选）：方案热缓存、问答缓存、连续打卡
```

### 3.2 双模式设计

前端通过 `VITE_USE_MOCK` 切换数据源：`true` 时全部走 localStorage 与本地算法，零后端即可完整演示；`false` 时走真实 API。这个设计让评审现场即使网络异常也能完整走通闭环，也是我们能在开发早期快速迭代流程的原因。

### 3.3 缓存策略

方案热缓存 `plans:hot:{部位}:{时长}:{场景}:{风险}` 300 秒、问答缓存 `qa:cache:{问题哈希}` 3600 秒、连续打卡 `user:streak:{uid}` 300 秒且打卡后主动失效。Redis 未配置时自动降级为进程内字典，因此单机演示无需额外组件，集群部署再挂 DCS。

### 3.4 工程实践

- 评估算法、方案匹配、安全校验、问答四段逻辑前后端同源，避免"演示一套、上线一套"。
- 建表、36 个方案、10 条知识库在服务启动时自动补种，空库启动即可用。
- 演示数据脚本 `seed_demo.py` 经真实评分函数生成，分数、问题点、建议与线上完全一致。
- 401 统一拦截清理凭证并跳转登录；跟练中离开有二次确认与 `beforeunload` 保护。

## 四、创新点

1. **可解释的分级评估**：四档风险 + 六维度问题点 + 红线独立判定，把"分数"翻译成"该做什么、不能做什么"。
2. **指南可溯源**：每条建议可点回 WHO / NHS / CSP 等机构原文，健康类产品里少见。
3. **安全优先的产品结构**：高风险用户在产品内拿不到方案，这不是弹窗提示，而是流程阻断。
4. **碎片化场景匹配**：以"3 分钟 / 工位 / 不用换衣服"为第一约束设计方案库，而不是把完整课程切片。
5. **双模式可演示架构**：同一套 UI 与算法，Mock 与云端一键切换，降低演示风险。

## 五、应用价值与推广

目标用户是办公人群、学生与久坐职业者。落地路径有三条：企业健康福利（工位场景 + 提醒）、高校健康教育（评估 + 碎片运动）、康复科随访辅助（低风险维持训练，高风险直接转诊）。

产品不追求替代医生或教练，定位是"久坐人群的第一道分诊与第一套动作"。这个定位决定了它的成本结构：不需要人工教练，不需要硬件，一部手机或一台电脑即可使用。

## 六、现状与后续计划

当前已完成：24 题评估、四档风险、红线拦截、36 方案库、跟练打卡、提醒、周月统计、改善趋势、部位关注度、指南页、问答页、收藏与自定义方案、演示数据脚本、云部署材料。

后续计划：

1. 补充真实用户可用性测试，验证 3 分钟评估的完成率与两周留存。
2. 增加动作示范图与视频，降低纯文字要领的理解成本。
3. 与可穿戴设备联动，用真实久坐时长替代页面计时提醒。
4. 在合规前提下引入匿名聚合数据，验证不同人群的风险分布。
