## 四、问题清单（按严重度）

### P0 —— 阻断级（不修复则"真实联通/演示真实性"不成立）

**F1. 前端与后端完全未联通（全 mock 模式）**
- 位置：`frontend/src/api/index.js`（全部函数为 localStorage 实现）、`vite.config.js`（/api 代理已配置但从未被使用）
- 现象：走查全程 network 中无任何 `/api/*` 真实请求，仅加载了 `src/api/index.js` 模块本身；PRD 承诺的 CodeArts Skills / 云数据库 / 云端推荐在代码内无真实接入路径（Skills 逻辑在 `src/mock/skills.js` 本地复制）。
- 影响：演示与真实产品是两套系统；"智能问答""云端评估"等卖点无法验证；后端缺陷被 mock 完全掩盖。
- 建议：明确"演示模式（默认 mock）/ 联调模式"开关（如 `VITE_API_MODE=real` 时 api 层走 axios/fetch 调后端，保留 mock 作离线回退），并在一键启动脚本中显式声明当前模式。

**F2. 后端注册接口不落库（缺 commit）**
- 位置：`backend/app/routers/auth.py` `register()` —— INSERT 后**无 `await session.commit()`**（对比 assessment/training/reminder 均有 commit）
- 现象：实测注册返回 200 与 token（user_id=1），但 SQLite `user` 表为空；随后所有需登录态接口（评估/方案/训练/提醒/问答）全部 401 `用户不存在`。
- 影响：一旦前端切到真实后端，用户注册即"幽灵账号"，全链路 401，产品不可用。
- 建议：`register()` 在 INSERT 后补 `await session.commit()`；并补一条联调冒烟用例（注册→带 token 请求任一接口 200）。

### P1 —— 高（直接影响核心体验）

**F3. 悬浮底栏遮挡长表单主操作按钮（实测复现）**
- 位置：`App.vue` 底部悬浮胶囊导航（fixed bottom:16px，z-index:100，深色 #1f1f1f）与各长表单页的底部主按钮
- 现象：在 819×883 视口下，评估页"下一步/提交评估"按钮矩形（y 813–857）**完全落入**悬浮导航矩形（y 765–863）内，且两者同为深色 #1f1f1f，按钮视觉上"消失"在导航里；实测正常坐标点击该按钮两次，均落到导航"方案"上并跳转 `/plans`。
- 影响：长表单（评估 8 题/步）用户滚到底部后点不到主 CTA 或误跳页；移动端（PRD 主场景）同样成立。
- 建议：①全局为内容区增加与导航等高的底部安全间距（导航 98px > 现 padding-bottom 80px）；②导航在非必要页面（如跟练全屏态）隐藏或改为浅色描边胶囊；③主按钮与导航同色时保证对比度与可点区域。

**F4. 方案推荐未携带评估结果（个性化闭环缺失）**
- 位置：`frontend/src/views/Plans.vue`（`risk_level: 'medium'` 硬编码）；`Home.vue`"今日推荐"为写死文案；`api/index.js` `recommend()`
- 现象：实测低风险用户获得"匹配度 100%"方案，匹配度与评估结论无关（仅过滤条件命中率）；评估产出的风险等级/问题点全程未参与推荐。
- 影响：PRD 核心卖点"根据评估结果推荐专属方案"名存实亡；高风险用户被整体挡在方案外，没有降级路径（如"低强度预防方案"）。
- 建议：评估结果落库后，方案页自动携带最近一次 risk_level + 问题点调用推荐；匹配度改为"评估匹配 + 条件命中"复合分；高风险给出就医引导 + 可选低强度替代方案。
