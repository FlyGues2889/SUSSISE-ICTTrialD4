### 演示链路修复与安全加固（走查新增）
- **演示登录不可用**：Mock 模式点「演示账号」只写入用户、未写 token，被路由守卫拦回登录页；`mock/demo.js` 的 `loadDemoData` 补写 token。
- **云端无演示入口**：新增 `POST /api/auth/demo-login`（白名单 `990001` / `990002`，不做密码校验），`Login.vue` 在 cloud 模式走真实接口并写入 token 与用户信息。
- **风险等级取错**：原逻辑按 `created_at` 取最新一条记录，高风险用户新做一次低风险腰背评估后拦截会失效。新增 `src/utils/risk.js` 的 `pickLatestRoundRisk`，取最新一轮（10 秒窗口）内的最高等级，`Home.vue` 与 `Plans.vue` 统一使用。
- **推荐未硬拦截**：`/plans/recommend` 在 `risk_level=high` 时直接返回 `{plans: [], blocked: true, message}`；前端首页不再展示方案卡（按钮改「查看健康依据」），方案页显示就医提示而非「切换条件」空态；Mock 层同步拦截。
- **分数展示越界**：加权满分 36.6 四舍五入落库为 37，报告出现「37 分（满分 36.6）」。`Assessment.vue` 增加 `fmtScore` 封顶展示，不改动评分与落库。
- **演示数据**：`seed_demo.py` 补 2 条收藏（方案 1、4），`--reset` 同时清理 `plan_favorite` 与 `custom_plan`；高风险账号两侧评估均改为 high。
