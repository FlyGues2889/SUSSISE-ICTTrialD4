## 1. 角色定位与职责边界

### 1.1 角色定位
负责本项目「专业」二字背后的全部运动康复内容、评估规则、方案库建设与 CodeArts Skills 能力封装，是评审「创新性 60%」中「运动康复专业壁垒 + 自定义 Skills」得分项的主要承担者。

### 1.2 职责边界

| 维度 | 本角色负责 | 本角色不负责 |
|---|---|---|
| 体态评估 | 问卷条目设计、评分规则、风险等级判定、安全红线规则 | 问卷前端页面、后端 API 实现 |
| 运动方案库 | 36+ 方案的专业内容编写、动作序列设计、禁忌人群标注 | 方案库 RDS 建表 SQL、前端方案展示 |
| 安全边界 | 就医提示触发规则、禁忌动作过滤逻辑 | 就医提示前端弹窗实现 |
| 自定义 Skill | 4 个 Skill 的业务规则定义与内容输入 | CodeArts 智能体平台配置、Skill 代码脚手架 |
| 知识库 | 智能问答知识库内容编写（问题+答案+关键词） | 知识库 RDS 建表、问答接口实现 |
| 接口契约 | 评估/匹配/安全判断的输入输出规则定义 | 接口前后端联调 |

### 1.3 与项目 PRD 的对应
- 承担 PRD 功能：F2 体态评估（问卷设计+评分规则）、F3 方案推荐（方案库+匹配规则）、F6 就医提示（安全红线规则）、F7 智能问答（知识库内容）。
- 承担 PRD 技术架构中：4 个 CodeArts Skills 的业务规则定义、运动方案库内容建设、知识库内容建设。

| 序号 | 条目 | 维度 | 评分 |
|---|---|---|---|

| N3 | 肩部是否有酸胀感，尤其是下午 | 疼痛频率 | 0无/1偶尔/2经常/3持续 |

| N5 | 颈部疼痛是否放射到手臂或手指 | **安全红线** | 0无/1偶尔→命中红线 |
| N6 | 久坐后是否需要用手支撑头部 | 姿势习惯 | 0无/1偶尔/2经常/3持续 |
| N7 | 肩颈活动时是否有咔咔响声 | 僵硬程度 | 0无/1偶尔/2经常/3持续 |
| N8 | 肩颈不适是否影响睡眠 | 疼痛频率 | 0不影响/1偶尔/2经常/3持续 |

#### 风险等级判定规则

| 条件 | 风险等级 | 系统响应 |
|---|---|---|
| 安全红线条目（N5/B5）得分 ≥ 1 | 高风险 | 强制就医提示，不推荐方案 |
| 区域总分 13-18 | 高风险 | 强制就医提示，不推荐方案 |
| 区域总分 6-12 | 中风险 | 推荐针对性干预方案 |
| 区域总分 0-5 | 低风险 | 推荐预防性方案 |

### 2.2 运动方案库建设（F3，P0）

#### 方案分类矩阵

| 时长 \ 部位 | 肩颈 | 腰背 | 全身 |
|---|---|---|---|
| 3 分钟 | 办公桌/站立/居家 各1个 | 办公桌/站立/居家 各1个 | 办公桌/站立/居家 各1个 |
| 5 分钟 | 办公桌/站立/居家 各1个 | 办公桌/站立/居家 各1个 | 办公桌/站立/居家 各1个 |
| 10 分钟 | 办公桌/站立/居家 各1个 | 办公桌/站立/居家 各1个 | 办公桌/站立/居家 各1个 |
| 15 分钟 | 办公桌/站立/居家 各1个 | 办公桌/站立/居家 各1个 | 办公桌/站立/居家 各1个 |

总计：4 × 3 × 3 = 36 个基础方案单元。

#### 方案内容模板

每个方案包含：
```json
{
  "plan_id": 1,
  "name": "办公桌前3分钟肩颈放松",
  "duration_min": 3,
  "target_area": "neck",
  "scene": "desk",
  "suitable_level": ["low", "medium"],
  "contraindication": "颈椎病急性期、肩袖损伤禁做",
  "movements": [
    {
      "seq": 1,
      "name": "颈部前屈后伸",
      "duration_sec": 30,
      "description": "缓慢前屈至下巴贴胸，再缓慢后伸，不过度仰头",
      "tips": "动作缓慢，感受颈部拉伸感",
      "image_url": null
    }
  ]
}
```

#### 方案编写要求
1. 每个动作基于运动康复教科书，不凭空创造
2. 标注禁忌人群（颈椎病急性期、腰椎间盘突出等）
3. 动作描述需通俗化，非专业用户能理解
4. 每个方案 5-8 个动作，动作间有逻辑递进（热身→拉伸→强化→放松）

### 2.3 安全边界规则（F6，P0）

| 规则 | 触发条件 | 系统响应 |
|---|---|---|
| 就医提示-红线 | N5 或 B5 得分 ≥ 1 | 强制弹出就医提示，不推荐任何方案 |
| 就医提示-高风险 | 区域总分 ≥ 13 | 弹出就医提示，不推荐方案 |
| 方案过滤-禁忌 | 用户评估结果命中方案禁忌人群 | 从推荐列表中过滤该方案 |
| 全局免责 | 所有页面底部 | "本工具提供健康运动指导，不替代医疗诊断" |

### 2.4 智能问答知识库（F7，P1）

预置 30+ 常见问题，覆盖：
- 肩颈类：脖子转动有响声正常吗 / 颈椎病能不能运动 / 头前伸怎么纠正
- 腰背类：腰肌劳损和腰椎间盘突出区别 / 久坐腰痛怎么缓解 / 弯腰驼背怎么改
- 习惯类：正确坐姿是什么 / 久坐多久需要起来活动 / 站立办公真的有用吗
- 安全类：什么情况需要就医 / 运动后疼痛加重正常吗 / 哪些动作腰椎间盘突出不能做

每条包含：标准问题、标准答案（200字以内）、匹配关键词、关联方案 ID。

## 3. CodeArts Skills 业务规则定义

### 3.1 posture_assessment Skill

**输入**：
```json
{
  "area": "neck",
  "answers": {"N1": 2, "N2": 1, "N3": 2, "N4": 3, "N5": 0, "N6": 1, "N7": 2, "N8": 1}
}
```

**输出**：
```json
{
  "risk_level": "medium",
  "total_score": 12,
  "problem_points": ["头前伸/圆肩姿势明显", "肩颈僵硬感频繁"],
  "suggestion": "建议每日进行肩颈碎片化运动，注意纠正头前伸姿势",
  "need_medical": false
}
```

**规则**：
1. 安全红线（N5/B5）得分≥1 → risk_level=high, need_medical=true
2. 总分≥13 → risk_level=high, need_medical=true
3. 总分6-12 → risk_level=medium
4. 总分0-5 → risk_level=low
5. problem_points：各维度中得分≥2的条目汇总

### 3.2 plan_matcher Skill

**输入**：
```json
{
  "risk_level": "medium",
  "problem_areas": ["neck"],
  "duration_min": 3,
  "scene": "desk"
}
```

**输出**：
```json
{
  "plans": [
    {"plan_id": 1, "name": "办公桌前3分钟肩颈放松", "match_score": 0.95},
    {"plan_id": 2, "name": "办公桌前3分钟全身微动", "match_score": 0.70},
    {"plan_id": 3, "name": "办公桌前5分钟肩颈深度拉伸", "match_score": 0.60}
  ]
}
```

**规则**：
1. 按 target_area 匹配 problem_areas（精确匹配 > 全身 > 其他部位）
2. 按 duration_min 精确匹配，无结果时取最接近的时长
3. 按 scene 精确匹配
4. 按 suitable_level 包含 risk_level 过滤
5. 按 contraindication 排除不适合方案
6. 按 match_score 降序取前 3

### 3.3 safety_check Skill

**输入**：
```json
{
  "risk_level": "high",
  "red_line_hit": true,
  "age": 35,
  "history": "颈椎病"
}
```

**输出**：
```json
{
  "safe": false,
  "need_medical": true,
  "message": "您的评估结果提示需要就医检查，建议前往骨科或康复科就诊。本工具暂不提供运动方案。"
}
```

### 3.4 qa_responder Skill

**输入**：`{"question": "脖子转动有响声正常吗"}`
**输出**：`{"answer": "颈部弹响...", "related_plans": [1, 5], "confidence": 0.85}`

**规则**：关键词匹配知识库 keywords 字段，取置信度最高的答案。
